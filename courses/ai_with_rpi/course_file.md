## Course Description

AI with Raspberry Pi teaches you to deploy real-world AI applications directly on a Raspberry Pi — completely offline, without cloud APIs, and without ongoing subscription costs. You will learn to run large language models locally, build AI voice assistants, generate images on-device, create AI agents, and connect AI to real hardware.

The course is structured into three tiers — Basic, Home, and Workplace — so learners can start small and progressively unlock more advanced AI capabilities. Every project is designed to be practical, reusable, and deployable in real environments.

By the end of the course, you will have built 10+ fully functional AI applications and understand how to design private, low-latency, edge AI systems from scratch.

## Curriculum / Modules

### Tier 1 — Basic ($97)

**Module 1: Raspberry Pi Setup**
- First-time Raspberry Pi configuration
- Installing Python, dependencies, and AI libraries
- Optimizing the system for AI workloads

**Module 2: AI Model Fundamentals**
- Overview of local AI model types (LLMs, image models, voice models)
- How to download and manage models on-device
- Running your first AI model via the terminal console

**Module 3: Flask AI Applications**
- Building web interfaces for AI using Flask
- Connecting AI model inference to a web frontend
- Structuring a reusable AI app architecture

**Module 4: Local LLM Server App**
- Deploying a local LLM as a server
- Building a full chat interface on Raspberry Pi
- Switching between different LLM backends

**Module 5: AI Image Generator App**
- Introduction to local image generation models
- Running image diffusion on Raspberry Pi
- Building a web UI for image generation and saving outputs
