## Course Description

Computer Vision Mobile Apps teaches you to build AI-powered camera apps for both Android and iOS using Unity 3D and the OpenCV C# wrapper. Write once, deploy to two platforms. You'll build 7 real applications including object detection, augmented reality, face detection, QR code reading, color detection, and document scanning — all with a clean, modern UI design. No prior C# experience needed; the course starts from the basics and teaches you everything you need.
