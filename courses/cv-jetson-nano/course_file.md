## What You Will Build

### Project 1 — Face Attendance System
- Recognize and log known faces in real time
- Alert on unknown face detection
- Store attendance records in a database
- RGB LED feedback for known/unknown status

**Components:** Raspberry Pi Camera V2, 10mm RGB LED, optional cooling fan

---

### Project 2 — Robot Car
- Full self-driving robot car assembly (from scratch)
- Lane following using basic image processing
- Object tracking — follow a colored target
- Keyboard-controlled spy robot mode

**Components:** L298 H-Bridge, Arduino MCU, DC motors x2, 18650 batteries, ball caster wheel, toggle switch, webcam or Raspberry Pi Camera

---

### Project 3 — Eye Tracking Camera Mount
- 2-axis servo-mounted camera that tracks objects or faces
- Smooth tracking using servo control
- 3D printed mount with custom design

**Components:** 9G Servo motors x2, Raspberry Pi Camera V2, wide angle lens, Arduino Uno + Sensor Shield, ribbon flex cable, bolts
