## Course Description

Computer Vision Game Development teaches you to build interactive games controlled by real body gestures using Python, OpenCV, and PyGame. You'll start from game development fundamentals, learn to write custom Python classes for UI elements like buttons, toggles, and sliders, add physics and animations, and build fully playable games. The Advanced plan teaches you to export your games as standalone executables — no Python installation required on the player's machine. Build your portfolio with games that genuinely impress.
