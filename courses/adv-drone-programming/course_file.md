## Course Description

Advanced Drone Programming teaches you to take full autonomous control of a DJI Tello drone using Python and computer vision. You'll implement gesture recognition to command the drone with body poses, build a selfie drone that tracks and follows you, create both basic and advanced face-following systems with PID control, and master 3-axis PID for smooth and stable autonomous flight. A free Python basics course and ebook are included for beginners. Compatible with both Tello and Tello Edu models.
