## Course Description

Computer Vision Interactive Games teaches you to build games where the physical world meets the digital. Using a projector, webcam, and a real ball, you'll create interactive wall or floor projection games that anyone can play. You'll train your own AI model to detect the ball accurately, then build games like Pest (click simulator), Football Kick, Crack the Wall, and more. This is a genuinely unique and crowd-pleasing project that can be deployed in events, schools, or entertainment venues.
